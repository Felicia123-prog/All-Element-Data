# All Element Data Dashboard

Streamlit dashboard voor uurdata van het station Zorg & Hoop.

## Functionaliteiten
- Dagbasis grafiek (uren 0–23)
- Maandbasis grafiek (dagen 1–31)
- Element-keuze:
  - Temperatuur
  - Relatieve vochtigheid
  - Visibilty
  - Windrichting (vector-gemiddelde)
  - Windsnelheid
  - Druk
- Statistiek-keuze (gemiddelde, maximum, minimum)
- Pastel glow UI
- Exportpaneel:
  - PNG
  - SVG
  - PDF
  - CSV
  - Excel

## Data
Plaats je dataset in `data/Merged_ZorgEnHoop.xlsx`.
